# Plan 14-01: Broker, per-endpoint injection, and redaction

## Goal

Provider keys resolve from the environment through the broker; the agent never handles a key string. A request to a host outside the policy allowlist gets no credential and the transport is untouched. Keys and tokens are redacted in audit records, event payloads, and model-facing memory recall.

## Starting Point

Providers declare `env_vars` but `ProviderModel` takes a raw `api_key` string. The broker sits between: it resolves the key from the environment and checks the request host against the seat policy before any transport call. Adapters stay untouched — the model builds the request once to learn the URL, resolves the credential, then builds it for real.

Read as the behavior spec: `.planning/research/v2-openshell-agentos.md` (credentials invisible to the agent, injected only for approved endpoints).

## Task 1: Broker and redaction

### `omes/credentials/broker.py` (new package `omes/credentials/`)

`CredentialBroker(policy, env=None)` (`env` a read-only mapping; None means `os.environ`):

- `key_for(provider, url) -> str`: parse the host from `url` (unparseable URL is a `ProviderError`); when the policy denies the host, raise `ProviderError("no credential for host <host>")` before touching the environment. For `requires_key=False` providers return `""`. Otherwise return the first non-empty value among `provider.env_vars`; none set raises `ProviderError("no credential for <name> (set A or B)")`.
- `redact(text) -> str`: `redact_text` plus every key this broker has resolved (cached at resolve time, never exposed).

### `omes/credentials/redact.py` (new)

`REDACTED = "[REDACTED]"`.

`redact_text(text, extra=()) -> str`: replace each string in `extra` (longest first, blanks skipped) and every match of the secret patterns with `[REDACTED]`:

- `sk-[A-Za-z0-9_....-]{8,}`, `xai-[A-Za-z0-9]{8,}`, `gh[pousr]_[A-Za-z0-9_]{8,}`, `AKIA[0-9A-Z]{16}`
- `Bearer [^\s]+` (the scheme word stays readable: `Bearer [REDACTED]`)
- `api[_-]?key` / `token` / `secret` assignments: `(?i)(api[_-]?key|token|secret)\s*[:=]\s*["']?[^\s"',}]+` keeping the key name, redacting the value.

Non-string input returns it unchanged.

### `omes/providers/base.py`

`ProviderModel(..., api_key="", broker=None)`. When `broker` is set, `complete` builds the request with an empty key to learn the URL, resolves `broker.key_for(provider, url)` (a refusal raises before the transport is touched), then rebuilds with the key and POSTs. Without a broker the behavior is exactly today's, including the missing-key error.

### Redaction wiring (three call sites, no behavior change otherwise)

- `omes/audit/log.py`: `append` redacts `reason` with `redact_text`.
- `omes/agent/harness.py`: `emit` redacts string payload values with `redact_text`.
- `omes/memory/provider.py`: `BuiltinMemoryProvider.prefetch` redacts its return with `redact_text` (recall is model-facing).

1. A broker over `{"XAI_API_KEY": "xai-secret-value"}` drives a `ProviderModel` with no `api_key` through `FakeTransport`: the POST carries `Bearer xai-secret-value`, the test code never assigns the key to the model, and `broker.redact` removes the value from a copied header string.
