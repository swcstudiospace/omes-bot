# Plan 19-01: Nightly curator pass over transcripts

## Goal

A nightly pass reviews each turn's transcript through the phase 4 curator: turns that earned a skill get one, and every reviewed turn checkpoints so re-runs never duplicate the work. Unearned turns write nothing.

## Starting Point

`review_turn(skills_root, user_text, tool_results)` already decides earned-vs-not and writes through `skill_manage`. The nightly pass maps journal-shaped transcripts onto that call and checkpoints reviewed turn ids.

## Task 1: Nightly pass

### `omes/routines/nightly.py` (new)

`nightly_pass(directory, skills_root, turns) -> dict`:

- `turns` is a list of `{"id", "messages"}`. A turn missing a non-blank string `id` or a `messages` list is a `ValueError` before anything runs.
- State file `{directory}/nightly.json`: `{"reviewed": [turn ids]}`. Missing file starts empty; corrupt JSON is a `ValueError` naming the file. Writes are atomic, after every turn (reviewed even when unearned, so re-runs skip it).
- Per unreviewed turn, map the transcript: `user_text` is the last `role == "user"` row's string content, skipping steer rows (`display_kind == "steer"`); absent user text means unearned. `tool_results` is one `{"success", "output"}` per `role == "tool"` row (`success` false when `is_error` is true; non-string content coerced with `str`, blank outputs dropped).
- Call `review_turn` with the mapped values. Collect `{"turn_id", "path"}` for each created skill.
- Return `{"created": [...], "reviewed": [...this run's turn ids...], "total_created": n}` where `n` counts this run's creations.

### Tests in `omes/tests/test_nightly.py`

1. An earned turn (user text with `save as a skill` plus `name:deploy`, one successful tool row) creates the skill (visible via `skill_view`); an unearned turn (plain chat) writes nothing; the state file lists both ids; the return reports one creation.
2. Re-running the same pass creates nothing new and reports no reviewed ids (both skipped from state).

Run `python3 -m pytest omes/tests -q` from `/root/src/repos/Omes-Bot`. Exit 0 is required.
