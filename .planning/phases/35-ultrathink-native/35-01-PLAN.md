# Plan 35-01: Ultrathink skills, routines, bridge tools

## Goal

Ultrathink's plan/track/ship flow runs natively in Omes: an
Omes-authored skill + turn routine (L1, no dependency) and a
registry family bridging the bun ultrathink CLI (L2), with zero
AGPL source copied into this repo (ULT-01, ULT-02).

## Global Constraints

- Repository root is `/root/src/repos/Omes-Bot`. Do not push.
- Do not modify `oh-my-pi/`, `hermes-agent/`, `~/src/repos/programming-desk`,
  `~/src/repos/claude-ultrathink` (read-only sources).
- No new third-party dependencies. No network, no live CLIs in tests.
- No verbatim copies of AGPL plugin text (skills, notices, CLI help).
  Describe behavior in Omes's own words.
- Phases 1–34 tests still pass; only roster/policy/composition assertions gain names.
- A completion claim cites the pytest command and its exit code.

## Starting Point

Ultrathink CLI (verified): `bin/ultrathink status`, `bin/ultrathink-mcp
track complete --state <json>`, `bin/ultrathink-mcp session mark
--state <json> <kicked-off|synced>`, `bin/ultrathink-ship
assess|pr|review|merge|status --state <json>`. All exec bun; all take
explicit paths. Grok-host flow: read `last-plan.json` from host
state dirs, read `specPath` when set, kickoff before other work.

## Task 1: L1 skill + routine

### `omes/skills/ultrathink/SKILL.md` (new, Omes-authored)

When a turn may carry an ultrathink plan: resolve the plan via the
routine, read the spec's ORIGINAL + Graph of Thought, run the
WORKFLOW waves, track via the bridge tools, ship via the bridge
tools. Names the bridge tools and the no-vendoring rule. `bots:
[bot-00-omes]`.

### `omes/routines/ultrathink_turn.py` (new)

`resolve_turn_plan(*, state_dirs=None, env=None) -> dict`: probe
`last-plan.json` in the host state dirs (explicit list, same order
as the Grok host: ULTRATHINK_STATE_DIR, GROK_PLUGIN_DATA,
GROK_HOME, HERMES_HOME, XDG/muse, PI_CODING_AGENT_DIR, CLAUDE
dir); return `{found, plan_path, spec_path, spec_exists}`; missing
file or bad JSON → `found: False` (never raise for a bad plan).

## Task 2: L2 bridge family

### `omes/tools/ultrathink.py` (new)

`ULT_TOOL_NAMES` (7): `ult_status`, `ult_track_complete`,
`ult_session_mark`, `ult_ship_assess`, `ult_ship_pr`,
`ult_ship_review`, `ult_ship_merge`. (`ship status` folds into
assess output; skip it.)

`UltrathinkContext`: `root` (checkout path, default `""` =
unconfigured), `run` (`(argv, timeout) -> {exit_code, stdout,
stderr}`, default subprocess). Every tool: unconfigured root →
not_configured; non-zero exit → upstream_error with tail;
JSON-decoded stdout echoed as `result`, else `output`.

`register_ultrathink_tools` with the drift guard. Approval on
`ult_track_complete` (writes tracker rows), `ult_ship_pr`
(push + PR), `ult_ship_review` (triggers review),
`ult_ship_merge` (merges). Reads need none.
