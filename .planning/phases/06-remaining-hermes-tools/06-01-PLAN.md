### `omes/tools/execute.py`

`execute_code(code, *, home, timeout=5) -> dict`

- Empty or whitespace-only `code` returns `{"error": ...}` and does not start a process.
- Otherwise write the code to a file inside `home` and run `[sys.executable, that_file]` with `cwd=home`, `shell=False`, and `timeout`.
- Return `{"stdout", "stderr", "exit_code"}`. A timeout returns an error and a non-zero exit. The process is killed.

### `omes/tools/mcp_client.py`

`mcp_call(command, tool, arguments, *, cwd) -> dict`

- `command` is an argv list. A string command is an error and starts nothing.
- Spawn that argv with `cwd=cwd`, `shell=False`, and a timeout. Write one JSON line to stdin: `{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name": <tool>, "arguments": <arguments>}}`.
- Read one JSON line from stdout. Return `{"result": <result>}`. Invalid JSON or a non-zero exit returns `{"error": ...}`.

### `omes/tools/browser.py`

`BrowserSession(transport)` where `transport.navigate(url) -> str` and `transport.snapshot() -> str`.

- `browser_navigate(url)` calls `transport.navigate` and returns `{"url", "page"}`.
- `browser_snapshot()` returns `{"page"}` from `transport.snapshot`.
- A missing transport returns `{"error": ...}` and does not open a socket.

### `omes/tools/approvals.py`

`ApprovalLog`.

- `approve(tool_name, approved_by, *, bot_id="bot-00-omes") -> dict`. `approved_by` must be a non-empty string and must not equal `bot_id`. A refused approval records nothing.
- `is_approved(tool_name) -> bool`.

### `omes/tools/registry.py`

`register` gains `requires_approval: bool = False`. Existing callers stay valid.

`dispatch` checks the flag before the handler. When it is true and the registry's approval log does not have that name approved, return `{"error": "approval required", "tool": <name>}` and do not call the handler. `ToolRegistry(approval_log=None)` treats every flagged tool as unapproved. Unflagged tools dispatch as they do now, including the JSON-string passthrough.

### `omes/tools/plugins.py`

`load_plugins(home, registry) -> list[str]`

- Load each `{home}/plugins/<name>/plugin.py` whose `<name>` matches `^[a-z0-9][a-z0-9._-]*$`.
- The file must define `register(registry)`. Call it. Return the tool names it registered.
- The resolved file must stay inside `home`. A symlink that leaves `home` is skipped and registers nothing.
- Use `importlib` from that path. Do not install a package.

`PLATFORM_TOOL_NAMES = ("execute_code", "mcp_call", "browser_navigate", "browser_snapshot")`.

`register_platform_tools(registry, *, home, browser=None)` registers those four. `execute_code` and `mcp_call` bind `home`. The browser tools bind `browser`.
