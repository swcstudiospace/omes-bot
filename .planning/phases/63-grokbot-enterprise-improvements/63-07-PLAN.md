# 63-07: Deployment kit

## Objective

Enterprises deploy containers or units, not `python -m` commands. Ship a canonical hardened image definition, a
renderer for four deployment targets, a hardening checker, and an image CI workflow. No secret is ever inlined: the host
reads its token from a file the platform mounts.

## Facts the artifacts must respect (verified in the code on 2026-10-09)

- Server command: `python -m omega_prime.mcp_server --root <root> --transport sse --host 0.0.0.0 --port 8000
  --token-file <path> --audit-log <path> --home <dir> --shutdown-grace 20 --log-format json` (Phase 62 flags plus the
  Phase 63 flags `--token-store PATH` and `--log-format {text,json}` that unit 63-08 adds). A container binds `0.0.0.0`,
  so a token file is mandatory: the host refuses to start without one (exit 2).
- Probes: liveness `GET /healthz`, readiness `GET /readyz` (503 while draining or degraded). Both are unauthenticated.
- Graceful stop: SIGTERM drains in-flight tool calls for up to `--shutdown-grace` seconds (default 20) and exits 0.
  Platform stop grace must be larger (30 s).
- The host needs a source-tree-shaped root: `<root>/omega_prime/contracts/{tool-rosters,policies}`. The image copies the
  `omega_prime/` package directory (minus tests and caches) to `/app/omega_prime`, runs with `--root /app` and
  `PYTHONPATH=/app`, and installs dependencies from `requirements-lock.txt` (146 pinned wheels, Python 3.12; the lock
  does not contain `omega-prime` itself).
- Writable paths: `default_registry` passes `<root>/omega_prime/memory` (this is ALSO a Python package directory; the
  store writes `MEMORY.md`/`USER.md` into it) and `<root>/omega_prime/sessions.db` to the growth tools, `<root>/omega_prime/skills`
  to skill management, and `home` to platform tools; the audit log path is configurable. A read-only root filesystem
  therefore needs a state directory hook (below). Grep `omega_prime/tools/` for any other write location before you
  finish and list every one in `docs/deploy.md`.
- Never write a secret into an image layer, compose file, unit file or manifest.

## Edge cases

- Deterministic rendering: no timestamps, sorted keys where a map is emitted, trailing newline.
- `render` refuses an `out_dir` that exists as a file; creates directories with default modes; never overwrites a file it
  did not generate unless `--force` (the CLI flag maps to `overwrite=True`).
- `name`/`image` are validated (DNS-label / reference grammar) before being interpolated into any artifact.
- `uid` must be >= 1000; `port` 1-65535.
