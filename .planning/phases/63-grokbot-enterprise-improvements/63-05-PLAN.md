# 63-05: Observability

## Objective

Prometheus metrics, W3C trace context with a request id on every response and audit record, and redacted NDJSON
logs, as standalone ASGI/logging modules the 63-08 integrator composes. No new dependency. Do not edit
`remote.py`.

## Change

1. `omega_prime/grokbot/metrics.py` per the contract in `63-CONTEXT.md`:
   - `MetricsRegistry` with `counter`, `gauge`, `histogram` (default buckets
     `0.005, 0.01, 0.025, 0.05, 0.1, 0.25, 0.5, 1, 2.5, 5, 10`), label-set children via `.labels(**kw)`
     (label names fixed at registration, values must be str; wrong label names raise `ValueError`),
     `.inc(n=1)`, `.set(v)`, `.observe(v)`, thread-safe, and `render() -> str` in Prometheus text format 0.0.4:
     `# HELP`/`# TYPE` lines, escaped label values (`\\`, `"`, newline), histogram `_bucket{le=...}`, `_sum`,
     `_count`, a trailing newline. Registering the same name twice with the same type returns the existing metric;
     a different type raises. Bound the number of label children per metric (default 1000; beyond it new children
     are folded into one `overflow` child) so a hostile client cannot blow up memory.
   - `MetricsMiddleware(app, registry, *, path_groups=...)`: pure ASGI, http scopes; metrics
     `omega_http_requests_total{method,path,status}` (status class `2xx` etc.),
     `omega_http_request_duration_seconds{method,path}`, `omega_http_in_flight`; path grouped to
     `/sse`, `/messages`, `/mcp`, `/healthz`, `/readyz`, `/metrics`, `/manifest.json`, `/admin`, else `other`
     (never raw paths or query strings). Observe duration when the response starts for streaming responses
     (SSE never ends) and decrement in-flight in a `finally`.
   - `MetricsInterceptor(registry, *, tool_names: Callable[[], Collection[str]])`: implements
     `ToolCallInterceptor`; `omega_tool_calls_total{tool,status}`, `omega_tool_call_duration_seconds{tool}`,
     `omega_tool_calls_in_flight`, `omega_tool_denials_total{code}`; the `tool` label is the name only when it is in
     `tool_names()`, else `unknown`.
   - `record_auth_failure(registry) -> Callable[[dict], None]` incrementing `omega_auth_failures_total{reason}`
     with reason limited to `missing|malformed|invalid|other`.
   - `register_build_info(registry, *, version, package_version)` -> gauge `omega_build_info{version,package_version} 1`.
   - `metrics_endpoint(registry, *, required_scope="read")`: raw ASGI endpoint (object with `__call__`) returning
     `text/plain; version=0.0.4; charset=utf-8`; with no principal -> 401, with a principal lacking the scope -> 403
     (use `principal_from_scope`; a scope-less deployment is the integrator's concern).
2. `omega_prime/grokbot/telemetry.py`:
   - `TraceContext` (frozen: `trace_id` 32 hex, `span_id` 16 hex, `flags` 2 hex, `parent_span_id | None`),
     `parse_traceparent(value)` (strict W3C: `00-<32hex>-<16hex>-<2hex>`, all-zero ids and version `ff` invalid,
     case-insensitive hex normalized to lowercase), `new_trace_context(parent=None)` (random ids; a parent keeps
     its `trace_id` and `flags` and gets a fresh `span_id`), `format_traceparent(ctx)`.
   - `RequestContextMiddleware(app)`: pure ASGI http; parse inbound `traceparent`, else new; request id =
     `trace_id[:16]`; set `scope["state"]["request_id"]`, `["trace"]`; response headers `X-Request-Id` and
     `traceparent` (the new span) added to `http.response.start`; a malformed inbound value is replaced, never
     echoed; inbound `X-Request-Id` is ignored (we mint our own so it cannot be forged into logs/audit).
   - `JsonLogFormatter(logging.Formatter)`: one JSON object per record (`ts` ISO UTC, `level`, `logger`, `msg`,
     plus `extra` fields that are JSON-safe, `request_id` when a contextvar is set); every string passed through
     `omega_prime.grokbot.audit.redact_sensitive`; exceptions as `exc` text, redacted.
   - `configure_logging(fmt="text", level="INFO")`: idempotent; configures the `omega_prime` logger tree with one
     stream handler (stderr) using `JsonLogFormatter` for `json` or a plain formatter for `text`; never touches the
     root logger's other handlers.
   - `AccessLogMiddleware(app, *, logger=None)`: pure ASGI; one record per http request on logger
     `omega_prime.access` AFTER the response completes or the connection ends: `method`, `path` (no query string),
     `status`, `duration_ms`, `principal` (id), `request_id`; no headers, no body, no query.
3. SPDX headers; docstrings.

## Edge cases

- Metrics rendering during concurrent updates is consistent per metric (take the lock while snapshotting).
- Histogram `le` formatting: `+Inf`, floats rendered without trailing noise.
- Middleware must not break streaming responses or `http.disconnect`; wrap `send`, never buffer.
- Unicode and control characters in label values are escaped.

## Tests

`test_grokbot_metrics.py`: golden Prometheus text for counter/gauge/histogram incl. escaping and bucket
cumulativity; label validation; type conflict; child cap overflow; middleware over a Starlette app via `TestClient`
(path grouping, status classes, in-flight returns to 0, streaming response observed at start); interceptor with
`run_tool_call` (ok/error/denied, unknown tool label); `metrics_endpoint` 401/403/200; `record_auth_failure`
reason bounding. `test_grokbot_telemetry.py`: traceparent parse table (valid, wrong version, zero ids, bad length,
uppercase), child context keeps trace id, middleware sets state + both headers, replaces malformed inbound value,
ignores inbound `X-Request-Id`; JSON formatter output is one valid JSON line, redacts a bearer token and an `omk_`
token, includes `request_id` from the contextvar; `configure_logging` is idempotent; access log has no query string
and no header values.
