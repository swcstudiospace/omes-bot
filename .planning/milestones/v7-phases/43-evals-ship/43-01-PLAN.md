the setup check, named in the template, and documented for GitBook

## Task 2: live probes

### `omes/substrate/probes.py` (new)

Read-only surface probes, runnable by hand:
- `config_from_env(env) -> dict`: `SUBSTRATE_URL` (default localhost),
  `SUBSTRATE_TOKEN`/`SUBSTRATE_TOKEN_GROK_BOT`, `HINDSIGHT_URL` (default
  Railway), `HINDSIGHT_API_KEY`/`HINDSIGHT_API_TOKEN`.
- `run_probes(config, transport) -> dict`: GET substrate `/healthz`, POST
  `/brief` (surface only), GET hindsight `/health` + `/version`. Every
  probe attempted; `{probes: {name: {ok, detail}}, passed}`. Details never
  carry secret values.
- `main(argv=None, env=None, transport=None) -> int`: prints one line per
  probe plus the verdict; exit 0 iff all pass.
- Manual run (not a test): brief/health against local substrate-mcp and
  hindsight health/version (all reachable without secrets) to prove the
  path; record commands + exit codes in the phase summary.

## Task 3: setup check
