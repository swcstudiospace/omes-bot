## Task 1: docs_search on the client

### `omes/substrate/client.py` (modify, additive)

`docs_search(query) -> dict`: empty/non-string query → `ValueError`; else
`POST /mcp` `tools/call docs_search` with `{"query": ...}`; returns the
parsed result dict as-is (`{ok, status, body}` / `{ok: false, error}`).
Transport/malformed failures raise `SubstrateError`.

## Task 2: substrate session

### `omes/substrate/session.py` (new)

`SubstrateSession(client, *, session_id=None, repo=None, branch=None,
graph_id=None, brief_dir=None, broker=None)`:
- `session_id` defaults to a uuid hex; `brief_dir` None skips the file write.
- `open() -> str`: idempotent; emits `session.start`, fetches the brief,
  writes `.substrate/BRIEF.md` under `brief_dir` when the brief is non-empty,
  caches and returns the brief. Never raises (`""` on any failure).
- `brief_block() -> str`: `""`, or `"## Substrate brief\n<brief>"` from cache.
- `on_prompt(text)`: emits `prompt` with the redacted, 240-char summary
  (non-string → type name). Never raises.
- `on_tool_call(name, arguments=None, ok=True)`: emits `tool.call`
  (`"<name> ok"` / `"<name> error"`); for `write_file`/`edit_file`/
  `patch_file` also emits `file.edit` with a best-effort string `path`.
  Tool arguments are never sent. Never raises.
- `on_turn_end(exit_reason)`: emits a `note` (`"turn ended: <reason>"`).
  Never raises.
- `close()`: idempotent `session.end` emit. Never raises.
- Every emit carries `session_id`, `repo`/`branch`/`graph_id` when set.

## Task 3: loop wiring

### `omes/agent/conversation_loop.py` (modify, additive)

## Task 4: docs tool family + contracts

### `omes/tools/substrate_tools.py` (new)

`SUBSTRATE_TOOL_NAMES = ("substrate_docs_search",)`;
`register_substrate_tools(registry, client) -> list[str]` (mirrors the family
shape, asserts the name set). Handler `substrate_docs_search(query: str)`:
empty query → `{"error": ...}`; `SubstrateError` → `{"error":
"substrate unreachable: ..."}`; `ok: false` → `{"error": <plane error>}`;
else `{"retrieval": <body>}`.
