## Starting Point

`omes/memory/hindsight.py` has the local bank-tagged `Hindsight`
(retain/retain_batch/recall). `HttpTransport` has JSON POST/GET. The live
hindsight-api v0.9.1 contract (verified against `/openapi.json`):
retain `POST /v1/default/banks/{bank}/memories` (`{items:[{content,...}]}` →
`{success, items_count}`); recall `POST .../recall` (`{query, types, budget,

(`{query, budget, max_tokens}` → `{text}`); pages `GET
.../knowledge-base/search?q=&limit=` (→ `{results, total}`). Auth is a
`Bearer` token (`HINDSIGHT_API_KEY`, `HINDSIGHT_API_TOKEN` fallback).

## Task 1: service client

### `omes/memory/hindsight_service.py` (new)

`HindsightError(Exception)`; `DEFAULT_BANK = "ultrathink"`;
`DEFAULT_BASE_URL` = the Railway hindsight-api public URL (override via
`HINDSIGHT_URL` at the wiring site in Phase 41).

`HindsightService(base_url=..., bank="ultrathink", *, transport=None,
broker=None, timeout=30.0)`: bank validated with the same rule as the local
`Hindsight` (shared helper, no drift); no broker → no `Authorization` header.

- `retain(items, *, context=None, document_id=None, tags=None) -> dict`:
  `items` is `list[str]` (wrapped to `{content}` with the shared context /
  document_id / tags) or `list[dict]` (must carry non-empty string `content`,
  else `ValueError`); blank strings are skipped, all-blank → `{"ok": True,
  "count": 0}` without a request. `POST` the RetainRequest; `success: true` →
  `{"ok": True, "count": items_count}`; `success: false` → `{"ok": False,
  "reason": ...}`. Transport/auth/malformed failures raise `HindsightError`
  (fail-closed: the caller must know the episode did not land).
- `recall(query, *, limit=5, types=None, max_tokens=2000) -> list[str]`:
  plugin-parity body (`types` default `["observation"]`, `budget: "low"`).
  Returns result `text` values sliced to `limit`; `limit` validated like the
  local bank; empty query → `[]`. Transport failures raise `HindsightError`.
- `reflect(query, *, budget="low", max_tokens=4096) -> str`: returns the
  `text` synthesis; empty query → `""`. Transport failures raise.
- `search_pages(query, *, limit=3) -> list[dict]`: `GET` with `q`/`limit`
  params; returns raw hit dicts; empty query → `[]`. Transport failures raise.
- Failure reasons pass through `broker.redact` when a broker is present;
  tokens never appear in exceptions.

## Task 2: local-fallback bridge

### `omes/memory/hindsight_bridge.py` (new)

`HindsightBridge(service, local)` with the local `Hindsight` call shapes:
- `retain(content)`, `retain_batch(items)` → service first, local on
  `HindsightError` (blank-skip semantics match the local bank either way).
- `recall(query, *, limit=5)` → service first, local on `HindsightError`.
- `reflect(query)` → service, `""` on `HindsightError`.
- `search_pages(query, *, limit=3)` → service, `[]` on `HindsightError`.
