# Plan 42-01: Graph ops + store-lock guard

## Goal

Desk-pack handoffs coordinate through substrate graph ops with lease
handling, and no direct backing-store client can exist under `omega_prime/`
without failing the build (GRP-01, LOCK-01).

## Global Constraints

- Repository root is `/root/src/repos/omega`. Do not push.
- Do not modify `oh-my-pi/`, `hermes-agent/`, `~/src/repos/programming-desk`,
  `~/src/repos/claude-ultrathink`, `~/src/repos/agent-substrate` (read-only sources).
- No new third-party dependencies. No network in tests (fakes/scripted peers only).
- Phases 1–41 tests still pass.
- A completion claim cites the pytest command and its exit code.

## Starting Point

`SubstrateClient._call_tool` does MCP `tools/call` with JSON content.
Upstream `graph_claim`/`graph_heartbeat` return JSON; `graph_release`/
`graph_complete` return plain text. Families flag mutating tools via an
`approvals` set. `omega_prime/tools/systems.py` holds injected `timescale`/
`greptime` query seams (no sockets, no URLs, default `None`).

## Task 1: graph ops on the client

### `omega_prime/substrate/client.py` (modify, additive)

- `graph_claim(graph_id, node_id, session_id, ttl_seconds=3600) -> dict`:
  non-empty-string validation (`ValueError`); `tools/call graph_claim`
  with surface default; returns the parsed lease dict. Fail-closed.
- `graph_release(graph_id, node_id) -> str`: validated; returns the raw
  result text. Fail-closed.
- `graph_complete(graph_id, node_id) -> str`: validated; returns the raw
  result text. Fail-closed.
- `graph_heartbeat(graph_id, node_id, token) -> dict`: validated
  (non-empty lease token); returns the parsed dict. Fail-closed.
- Private `_call_tool_text(name, arguments) -> str` for the plain-text
  tools; malformed envelopes raise `SubstrateError`.

## Task 2: graph tools + contracts

### `omega_prime/tools/substrate_tools.py` (modify)

`SUBSTRATE_TOOL_NAMES` grows to `substrate_docs_search`,
`substrate_graph_claim`, `substrate_graph_release`,
`substrate_graph_complete`, `substrate_graph_heartbeat` (in that order).
Handlers validate non-empty strings → `{"error": ...}`; `SubstrateError` →
`{"error": "substrate unreachable: ..."}`; claim/heartbeat return their
result dicts; release/complete return `{"result": <text>}`.
`approvals = {"substrate_graph_claim", "substrate_graph_release",
"substrate_graph_complete"}` (shared-state mutations; docs + heartbeat
stay unflagged), wired as `requires_approval=name in approvals`.

### Contracts (modify)

- Roster: append the four names in tuple order + header comment stays valid.
- Policy `tools.allow`: append the four names.

## Task 3: store-lock test

### `omega_prime/tests/test_store_lock.py` (new)

Fails the build when `omega_prime/` grows a direct backing-store client:
- Layer 1 (import guard): `ast`-parse every `omega_prime/**/*.py`; fail on imports
  of DB/redis driver tops (`psycopg`, `psycopg2`, `asyncpg`, `pg8000`,
  `redis`, `dragonfly`, `greptime`, `greptimedb`, `influxdb`, `questdb`).
- Layer 2 (endpoint guard): fail on endpoint literals for the three stores
  (`railway.internal` / `up.railway.app` hosts containing greptime,
  timescale, or dragonfly; `redis://` URLs; `:6379` / `:4000` ports)
  everywhere except the lock test itself (which states the patterns).
  Health-key fixtures (e.g. `{"greptime": True}`) are not endpoints.
- Documents the sanctioned exception: `systems.py` injected query seams
  (callables, no endpoints, default `None`) with an assertion that both
  stay `None` by default.
