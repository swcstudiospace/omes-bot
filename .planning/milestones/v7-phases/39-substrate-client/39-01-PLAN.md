## Starting Point

`omega_prime/providers/http.py` has `HttpTransport` (JSON POST/GET, retries, policy
allowlist, injectable `connect`). `omega_prime/credentials/broker.py` resolves keys per

Omega Prime is the `grok-bot` surface.

## Task 2: substrate client

### `omega_prime/substrate/__init__.py` (new)

Package docstring + `__all__` re-exports.

### `omega_prime/substrate/client.py` (new)

`SubstrateError(Exception)`; `EVENT_KINDS`, `MEMORY_KINDS` tuples mirrored from
upstream `types.ts` (comment cites the source file).

`SubstrateClient(base_url="http://127.0.0.1:7410", *, transport=None,
broker=None, surface="grok-bot", timeout=5.0)`:
- `base_url` must be http/https (else `ValueError`); trailing slash stripped.
- `transport` defaults to `HttpTransport(timeout=timeout)`; tests inject fakes.
- `surface` defaults to `grok-bot`; invalid surface (not a non-empty string) →
  `ValueError`. (Upstream SURFACES has no `omega_prime`; Omega Prime is the grok-bot.)
- Auth: `broker.key_for(_SUBSTRATE_PROVIDER, url)` with provider
  `name="substrate"`, `env_vars=("SUBSTRATE_TOKEN", "SUBSTRATE_TOKEN_GROK_BOT")`;
  no broker → no `Authorization` header (anonymous local runs).

Methods:
- `health() -> dict`: `GET /healthz`; raises `SubstrateError` on any failure.
- `brief(repo=None, branch=None, graph_id=None) -> str`: `POST /brief` with
  `{"repo","branch","graph_id","surface"}` (Nones dropped); returns markdown;
  **fail-open**: any failure → `""`.
- `emit(kind, summary, **fields) -> dict`: validates `kind` in `EVENT_KINDS`
  (`ValueError` otherwise), requires non-empty `summary` (`ValueError`);
  `POST /events` with surface default; returns the parsed body;
  **fail-open**: any failure → `{"stored": False, "error": <redacted reason>}`.
- `memory_write(scope, kind, text, *, trust=None, ttl=None, source_event=None)
  -> dict`: validates `kind`/`scope`/`text` (`ValueError`); `POST /mcp`
  JSON-RPC `tools/call memory_write`; returns the parsed result status dict;
  **fail-closed**: transport/auth/malformed failures raise `SubstrateError`.
- `memory_search(query, scope=None, limit=None) -> list`: `POST /mcp`
  `memory_search`; **fail-open**: any failure → `[]`.
- Malformed MCP envelopes (missing result/content/text, unparsable inner JSON
  where a dict is required) → `SubstrateError` for write, `[]` for search.
- Tokens never appear in exceptions or return values (broker errors carry no
  values; emit/search failure reasons pass through `broker.redact` when a
  broker is present).

## Task 3: tests

  results/exceptions; fake broker with canned token + redact passthrough.

  `ProviderError`.
