## Task 1: matcher + notices

### `omega_prime/agent/magic_keywords.py` (new)

- `MAGIC_KEYWORDS`: `(id, word, requires, label)` for ultrathink
  (`[]`), orchestrate (`[delegate_task]`), workflow
  (`[delegate_task, batch]` where `batch` = parallel dispatch
  available; Omega Prime always can, so the gate reads the tool map).
- `mask_non_prose(text)`: port of the Omp mask (fenced blocks via
  `^( {0,3})([`~]{3,})`, inline spans by exact backtick-run match,
  HTML/XML incl. comments + balanced close tags; length-preserving,
  newlines kept).
- `contains_magic_keyword(text, word)`: Omp boundaries with
  `[^\W_]` for `\p{L}\p{N}` (documented approximation; Python
  `re` has no `\p{}`), case-sensitive, tested on raw then masked
  text like `keywordInProse`.
- Notices: ultrathink verbatim (3 lines); orchestrate adapted
  (`task`→`delegate_task`, `edit/write`→file tools,
  `bash`→`run_terminal`, `lsp`→`lsp_diagnostics`,
  `todo`→`todo_write`, tool-conditional lines rendered from the
  enabled set); workflowz rewritten against
  `delegate_task`/routines (no eval kernel in Omega Prime — no
  `agent()/completion()/wait()/workpool()` fiction).
- `notices_for_turn(text, tools, settings=None) -> list[dict]`:
  enabled switches (global + per-id, default True), requires ⊆
  tools, rows shaped `{"role": "user", "content",
  "display_kind": "<id>-notice"}`.

### `omega_prime/agent/conversation_loop.py` (extend)

- `Agent.magic_keywords` field (default None = all on).
- In `_run_conversation_turn`, after appending the user row, extend
  messages with `notices_for_turn(str(user_message),
  agent.tools or {})` when enabled (skip non-string user rows).

### `omega_prime/tests/test_magic_keywords.py` (new)

ignored); requires gating (orchestrate skipped without

via `run_conversation` with `ScriptedModel` (notice row present,
