## Task 1: MCP server

### `omega_prime/mcp_server.py` (new)

- `build_server(registry, *, roster=None) -> Server`: `on_list_tools`
  maps registry schemas to MCP Tools (name/description/inputSchema),
  filtered to `roster` when given; `on_call_tool` dispatches by
  name with `arguments or {}`, returns `TextContent(dispatch
  payload)`; unknown/policy/approval denials come back as
  `isError` results with the registry's error text.
- `default_registry(root, home) -> ToolRegistry`: wires every
  family with safe defaults (cwd-rooted coding/growth/ide,
  home-rooted platform, default contexts elsewhere — unconfigured
  clients fail safe; delegate skipped: it needs a live parent
  agent with a model).
- `main()`: load roster names from
  `contracts/tool-rosters/omega-prime.yaml`, build the default registry
  for cwd, serve over stdio. `python -m omega_prime.mcp_server`.

### `omega_prime/tests/test_mcp_server.py` (new)

- Handler level: list names/descriptions/schemas match the
  registry; roster filter drops extras; call echoes dispatch
  incl. unknown tool + approval-required `isError`.
- Dogfood: spawn the server over real stdio via the repo's own
  `mcp_session_call` (argv `[sys.executable, "-m",
  "omega_prime.mcp_server"]`, cwd=repo root): initialize + list + one
  read-only call (`lead_roster_status`-shaped or similar safe
  read) round-trips.

## Task 2: host profiles

### `omega_prime/hosting/openshell/sandbox-policy.yaml` (new)

Genuine-schema profile: workdir included, repo + `.venv` readable,
writes confined to work scratch + tmp, network default-deny with a
commented stanza showing how to open hosts. Header documents the
run commands (`openshell sandbox create --name omega_prime --policy
... --no-auto-providers`, then run the server inside).

### `omega_prime/hosting/agentos/NOTES.md` (new)

Honest notes: AgentOS VMs are Wasm/V8 and do not run CPython, so
Omega Prime does not execute inside an AgentOS actor; supported patterns
are (a) Omega Prime host on a VM/VPS/sandbox with the AgentOS actor
calling it over MCP/HTTP, (b) revisit if a Python/WASI path
matures. No invented APIs.
