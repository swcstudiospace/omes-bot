## Task 1: Persistence, modes, hooks, and learning

### `omega_prime/session/persist.py` (new)

`SCHEMA_VERSION = 1`.

- `save_session(directory, session_id, messages, metadata=None) -> str`. `session_id` must match `^[a-zA-Z0-9][a-zA-Z0-9._-]*$`. Write `{directory}/sessions/{session_id}.json` atomically (temporary file plus rename) with `{"schema": 1, "id", "messages", "metadata"}`. `messages` must be a list of dicts. Return the file path.
- `load_session(directory, session_id) -> dict`. Unknown id, unreadable JSON, or a schema mismatch raises `KeyError` / `ValueError` respectively and returns nothing partial.
- `save_task(directory, task_id, title, status="open", notes="") -> str` and `load_task(directory, task_id) -> dict` with the same id rule, atomic write, and error shapes under `{directory}/tasks/`. `status` must be one of `open`, `doing`, `done`.

### `omega_prime/agent/modes.py` (new)

- `PLAN_MODE_BLOCKED = frozenset({"write_file", "patch_file", "edit_file", "execute_code", "run_terminal", "mcp_call"})`.
- `apply_plan_mode(tools: dict) -> dict`. Return a copy where each blocked name present in `tools` is replaced by a wrapper with the same signature shape (`(*args, **kwargs)`) that returns `"error: plan mode forbids <name>"` without calling the original. Unblocked tools are the identical function objects.

### `omega_prime/agent/extensions.py` (new)

`ExtensionHooks`:

- `register_before_model(fn)` appends `fn(messages, tools)`. Non-callable is a `TypeError`.
- `run_before_model(messages, tools) -> dict | None`. Run hooks in registration order; a hook may mutate `messages` in place. The first `{"stop": True, ...}` dict wins and later hooks do not run. Anything else continues. No hooks means no stop.

### `omega_prime/agent/security.py` (new)

`screen_argv(argv) -> dict`. Return `{"ok": True}` or `{"ok": False, "reason": ...}`:

- Not a list, empty, or any non-string or empty part is refused.
- The first part's basename in `{"sudo", "su", "doas", "runas", "mkfs", "dd", "shutdown", "reboot", "halt", "poweroff"}` is refused.
- `rm` with `--no-preserve-root`, or with `/` as a target, is refused.
- Any part containing NUL is refused.

### `omega_prime/agent/conversation_loop.py`

`Agent` gains `plan_mode: bool = False` and `extensions: Any = None`. After `wrap_tools`, when `plan_mode` is true, replace `agent.tools` with `apply_plan_mode(agent.tools)`; the existing `finally` still restores the true original. Before `run_before_model` each iteration, run the extension hooks when `agent.extensions` is set; an extension stop ends the turn the same way a legacy-hook stop does, before billing.

### `omega_prime/learning/` (new package)

- `autolearn.py`: `Autolearn(skills_root, *, min_tool_calls=1)`. `consider_turn(tool_calls, name, content) -> dict`: when `tool_calls < min_tool_calls`, or `name`/`content` is blank, return `{"learned": False, "reason": ...}` and write nothing. Otherwise call `skill_manage("create", ...)` (falling back to `"edit"` when the skill already exists) and return `{"learned": True, "skill": name}` on success or `{"learned": False, "reason": ...}` when the manager reports an error. No other writer is used.
- `goals.py`: `GoalStore(directory)`. `set_objective(text)` (non-blank), `add_step(text)`, `complete_step(index)`, `status() -> {"objective", "steps": [{"text", "done"}]}`. Persisted as one JSON file, atomically, on every mutation; a new store on the same directory sees the old state.
- `advisor.py`: `format_advisories(notes) -> str` where each note is `{"note", "severity"?, "advisor"?}`. One `<advisory severity="...">` element per note on its own line, XML-escaped text and attributes; unknown severity is a `ValueError`. Valid severities: `nit`, `concern`, `blocker`. `advise(note, severity="nit", advisor=None) -> dict` returns `{"note", "severity", "advisor", "rendered"}` for one note.

### `omega_prime/tools/exec_jobs.py` (new)

`JobControl(cwd)`:

- `start(argv, *, timeout=30) -> str`. `argv` must pass `screen_argv`; a refusal raises `ValueError` naming the reason and starts nothing. Spawn with pipes, `cwd`, `shell=False`. Return a job id (`job-1`, ...).
- `poll(job_id) -> dict`: `{"id", "running", "exit_code?", "stdout"?, "stderr"?}`. Streams are surfaced only after exit. Unknown id is a `KeyError`.
- `wait(job_id, timeout=None) -> dict`: block until exit or timeout (`TimeoutError`, job keeps running), then like `poll`.
- `kill(job_id) -> dict`: terminate, then kill after 5 seconds; reap. Return the final `poll` shape. Unknown id is a `KeyError`.

Every started job is reaped exactly once; a second `wait` after exit returns the cached result without touching the process.

Add one `VENDOR.md` line listing the Omp sources this task adapted.

### Tests in `omega_prime/tests/test_modes.py`

1. Save a session transcript and a task, then load both from new handles on the same directory: messages, metadata, title, and status round-trip. An unknown id raises `KeyError`; a bad status is a `ValueError` on save.
2. In plan mode a scripted turn calling `write_file` gets the refusal as the tool result, the fixture file is unchanged, and `agent.tools` is the identical map object after the turn. A read tool in the same turn still runs.
3. An extension hook registered before the turn mutates the outgoing messages (observed in `model.seen`), and a second hook returning `{"stop": True}` ends the turn with no model call and no later hook running.
4. `consider_turn` with zero tool calls writes nothing; with calls it creates the skill (visible via `skill_view`), and a second call for the same name edits rather than failing.
5. A goal store sets an objective, adds two steps, completes one; `status` shows it; a new store on the same directory agrees.
6. `format_advisories` renders two notes with severities and an advisor name, XML-escaped; an unknown severity raises `ValueError`.
7. A job running `[sys.executable, "-c", "print('hi')"]` completes with exit 0 and `stdout == "hi\n"`. A refused argv (`sudo ...`) raises `ValueError` and starts nothing. A sleeping job reports `running` on `poll` and is dead after `kill`.
8. `screen_argv` refuses `rm -rf /` and a NUL byte, and accepts `[sys.executable, "-c", ...]`.
