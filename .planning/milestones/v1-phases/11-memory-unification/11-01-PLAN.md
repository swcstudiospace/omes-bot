## Task 1: Three clients on one store

### `omega_prime/memory/omp.py` (new)

`OmpMemory(store)`:

- `retain(content, *, target="memory") -> dict`: `store.add(target, content)`; return `{"ok": True}` on success or `{"ok": False, "reason": ...}` on a store error. Blank content is refused without calling the store.
- `recall(query, *, limit=5) -> list[str]`: entries from both targets whose text contains `query` as a case-insensitive substring, memory target first, stable insertion order, at most `limit`. Blank query returns `[]`. `limit` must be a positive int.
- `edit(old_text, new_content, *, target="memory") -> dict`: `store.replace`; same ok-shape as `retain`.
- `forget(old_text, *, target="memory") -> dict`: `store.remove`; same ok-shape.

### `omega_prime/memory/hindsight.py` (new)

`Hindsight(store, bank="default")`:

- `bank` must be a non-empty string without whitespace or brackets.
- `retain(content) -> dict`: retain as `"[hindsight:{bank}] {content}"` on the `memory` target. Blank content refused.
- `retain_batch(items: list[str]) -> dict`: retain each; return `{"ok": True, "count": n}` where `n` is the number kept (blanks skipped, not errors).
- `recall(query, *, limit=5) -> list[str]`: this bank's entries whose content (after the tag) contains `query` case-insensitively, tag stripped, stable order, at most `limit`. Other banks' entries never match.

### `omega_prime/memory/mnemopi.py` (new)

`Mnemopi(store, bank="default")`:

- Same bank rule as hindsight.
- `remember(content) -> str`: store as `"[mnemopi:{bank}:{id}] {content}"` on the `memory` target and return `id` (`mem-1`, ...; the next id scans this bank's existing tags for the max). Blank content is a `ValueError` and writes nothing.
- `recall(query, top_k=5) -> list[dict]`: this bank's entries matching `query` case-insensitively, each `{"id", "content"}` with the tag stripped, stable order, at most `top_k`.
- `get(memory_id) -> dict | None`: `{"id", "content"}` or `None`.
- `forget(memory_id) -> bool`: remove the tagged entry; `True` when one was removed.

All three clients reload through the store they were given: a second client on a new `MemoryStore` over the same directory sees what the first wrote (the store loads from disk on construction).
