### `omes/skills_runtime/manager.py`

`skill_manage(action, name, content=None, category=None, old_string=None, new_string=None, *, skills_root) -> str`

Returns a JSON string. `skills_root` is required (tests pass a temp directory). Actions:

- `create` — write `{skills_root}/{name}/SKILL.md` (or `{skills_root}/{category}/{name}/SKILL.md` when category is set). Refuse when the name already exists. Refuse when the directory exists and is not an empty real directory.
- `edit` — replace the existing `SKILL.md` with `content`.
- `patch` — replace one exact occurrence of `old_string` with `new_string` in `SKILL.md`. Zero matches or more than one match returns an error and leaves the file byte-for-byte unchanged.

`skill_view(name, *, skills_root) -> str` returns JSON whose `content` is the `SKILL.md` bytes. A second call, including one from a fresh process reading the same directory, loads that file. Missing skill returns a JSON error.

### `omes/skills_runtime/guards.py`

Apply these before any write:

- Name matches `^[a-z0-9][a-z0-9._-]*$`, length 1..64. `..`, slashes, and absolute paths are refused and no file is written.
- Category, when set, is one path segment with the same pattern.
- Frontmatter is a `---` block of `key: value` lines (no nested YAML), closed by `---`, with `name` and `description`, and a non-empty body. Description length is at most 1024. On `create`, the description is at most 60 characters. `edit` and `patch` do not apply the 60-character cap.
- Content length is at most 100_000 characters.
- The resolved skill directory must stay inside `skills_root`. Reject a symlink whose target leaves the root. A failed guard writes nothing.

### `omes/memory/store.py`

`MemoryStore(directory)` persists `MEMORY.md` and `USER.md`. Entries are joined by `\n§\n`.

- `add(target, content)` appends a stripped entry. Empty content is an error. A duplicate entry is a success and does not append again. An add that would exceed 2200 characters (`memory`) or 1375 (`user`) is an error and leaves the file unchanged.
- `replace(target, old_text, new_content)` replaces the one entry that equals `old_text`, or the one entry that contains it when none equals it. Two distinct matches is an error and leaves the file unchanged.
- `remove(target, old_text)` removes that entry under the same match rule.
- `load_from_disk()` reloads. A new `MemoryStore` on the same directory sees an entry written by an earlier store.
- An entry containing the delimiter character `§` is refused. Nothing else is a threat scanner in this phase.

### `omes/memory/provider.py` and `omes/memory/manager.py`

- `MemoryProvider` is an abstract base with `name`, `is_available`, `initialize`, `get_tool_schemas`, and `handle_tool_call`. `prefetch(query, *, session_id="")` defaults to `""`. `is_trivial_prompt` matches the Hermes greeting/acknowledgement list, including empty text and slash commands.
- `BuiltinMemoryProvider` uses `MemoryStore`. `prefetch` returns `""` for a trivial query. Otherwise it returns the rendered memory block, which includes every stored memory entry.
- `MemoryManager.add_provider` and `prefetch_all` concatenate provider prefetches. `handle_tool_call("memory", args)` dispatches to the builtin provider.

### `omes/session/search.py`

`SessionStore(path)` uses the stdlib `sqlite3` module.

- `append(session_id, role, content)` stores one message.
- `session_search(query, *, store) -> str` returns JSON. `messages` contains stored rows whose content has `query` as a literal substring, and no other rows. A new `SessionStore` on the same file finds a message the previous store appended. An empty query returns a JSON error and no rows.

### `omes/agent/curator.py`

`review_turn(*, skills_root, user_text, tool_results) -> dict` with `created` (bool) and `path` (str or None).

A skill is earned only when all three are true:

1. `is_trivial_prompt(user_text)` is false.
2. `user_text` contains `save as a skill` (case insensitive) and a `name:<slug>` token whose slug passes the skill name guard.
3. `tool_results` contains at least one mapping with `success` true and a non-empty string `output`.

When earned, build `SKILL.md` through `skill_manage(action="create")`. The description is `Use when the user asks to save this procedure.` The body contains the earned `output` verbatim and contains no other procedure text. `path` is the `SKILL.md` path.

When any condition fails, do not call `skill_manage`. The skills directory's files and bytes stay unchanged, and `created` is false.
