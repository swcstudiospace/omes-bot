## Task 1: Framed stdio sessions plus two registry tools

### `omes/tools/rpc.py` (new)

`RpcConnection(argv, *, cwd, timeout=10)`

- `argv` is a non-empty list of strings. Anything else raises `ValueError` and starts nothing.
- Spawn with `stdin/stdout` pipes, `stderr` inherited as devnull, `cwd=cwd`, `shell=False`. A daemon reader thread frames Content-Length messages (`Content-Length: <n>\r\n\r\n` + `<n>` UTF-8 bytes) into a queue; over-long headers or bodies are a framing error. Cap: 1 MiB header scan, 16 MiB body.
- `send(message: dict)` writes one frame under a lock.
- `read_message(timeout=None) -> dict` returns the next inbound message, raising `TimeoutError` on expiry and `EOFError` when the process dies with the queue empty.
- `close()` closes stdin, waits up to 5 seconds, then kills and reaps. Idempotent.

### `omes/tools/lsp.py` (new)

`LspSession(connection)` speaking JSON-RPC 2.0 with numeric ids:

- `start(timeout=None)`: send `initialize` (`processId`, `rootUri`, empty capabilities), require the response, then send the `initialized` notification. A missing or error response raises.
- `open_document(path, language_id, text)`: send `textDocument/didOpen` with a `file://` uri. Return the uri.
- `diagnostics(uri, timeout=None) -> list`: read until a `textDocument/publishDiagnostics` for `uri` arrives; skip unrelated messages. Return its `diagnostics` list (may be empty). Timeout raises `TimeoutError`.
- `shutdown()`: send `shutdown`, require the response, send `exit`. Usable as a context manager that always closes the connection.

### `omes/tools/dap.py` (new)

`DapSession(connection)` speaking DAP (`seq`-numbered requests, responses matched by `request_seq`, events stashed in order):

- `start(timeout=None)`: send `initialize` (`adapterID`, `pathFormat`), require success, then read until the `initialized` event.
- `launch(program, extra=None, timeout=None)`: send `launch` with `program` and require success.
- `set_breakpoints(path, lines, timeout=None) -> list`: send `setBreakpoints` (`source: {path}`, one `breakpoints` entry per line); return the response `breakpoints` list.
- `configuration_done(timeout=None)`: send `configurationDone` and require success.
- `wait_stopped(timeout=None) -> dict`: return the first `stopped` event body. Timeout raises `TimeoutError`.
- `threads(timeout=None) -> list`, `stack_trace(thread_id, timeout=None) -> list`: the response bodies' lists.
- `disconnect(timeout=None)`: send `disconnect`, then close. Context manager like `LspSession`.

A response with `success: false` raises `RuntimeError` naming the command.

### `omes/tools/ide.py` (new)

`IDE_TOOL_NAMES = ("lsp_diagnostics", "dap_stop")`.

`register_ide_tools(registry, root)` binds `root` (a `FileWorkspace` root jail applies to every path):

- `lsp_diagnostics(command, path, language_id="python", timeout=10) -> dict`. `command` must be an argv list; a string is an error that starts nothing. The file must exist under the root and be UTF-8. Open the document, collect its diagnostics, shut down. Return `{"path", "diagnostics"}`. A timeout or protocol error returns `{"error": ...}` and the server is reaped.
- `dap_stop(command, path, line, timeout=10) -> dict`. `command` must be an argv list. The file must exist under the root; `line` must be a positive int. Launch, set the one breakpoint, `configurationDone`, wait for the stop, read threads and the stopped thread's frames, disconnect. Return `{"stopped": True, "reason", "thread_id", "frames": [{"name", "line"}], "breakpoints"}`. Failures return `{"error": ...}` with the adapter reaped.
