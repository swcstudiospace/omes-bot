## Task 1: Registry and the coding tools

Read, do not edit, as the behavior spec:

- `hermes-agent/tools/registry.py`
- `hermes-agent/tools/file_operations.py`
- `hermes-agent/tools/patch_parser.py`
- `hermes-agent/tools/file_operations_search.py`
- `hermes-agent/tools/terminal_tool.py` (local backend only)
- `hermes-agent/tools/todo_tool.py`
- `hermes-agent/tools/clarify_tool.py`
- `hermes-agent/tools/web_tools.py`
- `hermes-agent/tools/vision_tools.py`

Write under `omes/tools/`:

- `registry.py` — `register(name, description, parameters, handler)`, `schemas()`, `dispatch(name, arguments) -> str`. `dispatch` returns a JSON string. An unknown name returns a JSON error and does not raise. Handlers return JSON-serializable objects.
- `file_ops.py` — `read_file` and `write_file`, rooted at a directory. Paths that escape the root are errors. `patch_file` applies a unified diff to one file and leaves the file unchanged when the hunk context does not match.
- `search.py` — `search_text` finds a literal string under the root and returns matching relative paths.
- `terminal.py` — `run_terminal` runs an argv list (not a shell string) with the working directory inside the root and a timeout. Capture stdout, stderr, and the exit code.
- `todo.py` — `todo_write` replaces the task list and `todo_read` returns it.
- `clarify.py` — `clarify` records the question and returns it.
- `web.py` — `web_search` and `web_extract` call an injected transport. No default network client.
- `vision.py` — `vision_analyze` calls an injected transport. No default network client.
- `coding.py` — `register_coding_tools(registry, root, web=None, vision=None)` registers the names above.
- `offer.py` — `offered_schemas(registry, roster_names)` returns schemas whose names are in the roster. A registered tool absent from the roster is omitted.

Update `omes/contracts/tool-rosters/omes.yaml` so `tools` lists exactly the names `register_coding_tools` registers. Empty list is no longer correct.

Tests in `omes/tests/test_tools.py`:

1. `dispatch` of `read_file` returns the bytes written by `write_file` in a temp root.
2. `patch_file` changes a matching file and leaves a mismatched file byte-for-byte unchanged.
3. `search_text` finds a fixture and does not return a path outside the root.
4. `run_terminal` runs `["python3", "-c", "print(1)"]` and reports exit code 0. A path outside the root is refused.
5. `todo_write` then `todo_read` round-trips. `clarify` returns the question it was given.
6. `web_search` and `vision_analyze` return the injected transport's payload and do not open a socket.
7. A name absent from the roster is not in `offered_schemas`, even if it is registered.
8. `dispatch` of an unknown name returns a JSON error.

Run `python3 -m pytest omes/tests/test_shell.py omes/tests/test_loop.py omes/tests/test_tools.py -q` from `/root/src/repos/Omes-Bot`. Exit 0 is required.
