## Goal

`omega_prime.agent.conversation_loop.run_conversation` runs a tool round and a text finish. The system prompt stays byte-stable, a steer is its own user row, compression is the only rewrite of prior context, and an interrupt stops the loop.

## Task 1: Port the iteration and its invariants

Read, do not edit:

- `hermes-agent/agent/AGENTS.md` (message-flow invariants)
- `hermes-agent/agent/conversation_loop.py` function `run_conversation` and the iteration in `_run_conversation_turn` (the `while` that calls api retry, `normalize_model_response`, `run_tool_round` or `finish_text_response`, then `finalize_turn`)
- The phase modules those names come from under `hermes-agent/agent/turn_*.py`, plus `prompt_builder.py` and the compression entry the turn actually calls

Write under `omega_prime/agent/` (package, alongside the existing `.gitkeep`):

- `conversation_loop.py` — `run_conversation(agent, user_message, system_message=None, conversation_history=None, task_id=None) -> dict` with `final_response` and `messages`. The iteration checks interrupt, checks the iteration budget, calls the model, then either runs the tool round or finishes text, then finalizes.
- `turn_tool_round.py` — `run_tool_round`. Append the assistant tool-call message and one tool message per call. If a steer is pending, append a new `{"role": "user", ...}` row after the tool message. Do not edit the tool row.
- `turn_final_response.py` — `finish_text_response`.
- `turn_finalizer.py` — `finalize_turn`.
- `prompt_builder.py` — build the system prompt once when the conversation starts. Later iterations reuse that same string object / equal bytes. Do not rebuild it after a tool round.
- `compression.py` — `compress_messages(messages) -> messages`. This is the only function allowed to rewrite already-appended messages. It may replace older turns with a summary. It must leave the original system prompt bytes unchanged.
- `budget.py` — an iteration budget. When remaining hits 0, the loop stops even if the model asked for another tool.
- `interrupt.py` — a flag the loop reads at the start of each iteration. When set, `run_conversation` returns without another model call.
- `session_lease.py` — an in-process lease taken for the turn and released on the way out, including on failure.
- `model.py` — a small model protocol plus `ScriptedModel` whose `complete(messages, tools)` returns scripted assistant messages and records the messages it saw.

`Agent` can be a small dataclass the loop reads (`model`, `tools` as a name→callable map, `max_iterations`, `budget`, `interrupt`, `pending_steer`, `lease`). Do not port `AIAgent.__init__`'s 60 parameters.

Chrome that `conversation_loop.py` imports today (`tui_gateway`, `hermes_cli` billing and account, MoA, vision-history image bundling) is out of this task. Do not create shims that pretend those calls succeeded.

Tests in `omega_prime/tests/test_loop.py`, all through `run_conversation` and a `ScriptedModel`:

1. After a tool round the system message content is byte-for-byte the content from the first model call.
2. A pending steer becomes its own user message immediately after the tool message, and the tool message content is unchanged.
3. Appending messages during the turn is allowed. Replacing or editing an earlier message is allowed only when `compress_messages` runs. A test double wraps the message list and fails if any other code rewrites an earlier item. Call `compress_messages` once in that test and show the system bytes still match.
4. With the interrupt set after the first model response and before a second iteration, the model is called once.
5. `max_iterations` of 1 stops after one model call while the scripted model still wants a tool.
6. The lease is released after a turn, and a turn that raises still releases it.
