# Plan 08-01: Port the Omp edit pipeline

## Goal

The agent applies a well-formed edit to a fixture file, rejects a bad hunk without touching the file's bytes, and runs a deterministic repair pass that places a hunk the exact apply could not: wrong header line numbers are re-anchored by unique context search, and whitespace-only context differences match fuzzily. A hunk that matches nowhere, or in more than one place, is rejected. The repair is deterministic: no model call, no tree-sitter, no new dependency.

## Task 1: Exact-first pipeline with deterministic repair

### `omega_prime/tools/edit_pipeline.py` (new)

`apply_edit(original: str, diff: str) -> tuple[str, str]`

Return `(updated_text, method)`. Raise `PatchMismatch` / `PatchError` from `file_ops` without producing a partial result. The module imports the private hunk helpers from `omega_prime.tools.file_ops` (same package) rather than re-parsing diffs.

Passes, in order; the first pass that places every hunk wins:

1. `exact`: `apply_unified_diff(original, diff)`. Method `"exact"`.
2. `offset`: re-anchor by unique context search. For each hunk in order with the running shift, try the stated position first; otherwise scan the whole current text for positions where every context and removed line matches byte-for-byte. Exactly one candidate is required: zero or more than one fails the whole pass. Method `"offset"`.
3. `fuzzy`: like `offset`, but a position matches when every context and removed line compares equal after stripping leading and trailing whitespace. Context lines keep the file's own bytes; only removed lines are replaced by added lines. Unique candidate required. Method `"fuzzy"`.

Comparison strips the line terminator the way `_line_text` does, so a CRLF file matches an LF hunk on content; added lines are written with `\n`. A diff that is malformed (`PatchError` on parse) fails before any pass and is never repaired. An empty hunk body that matches everywhere is ambiguous and fails the repair passes.

### `omega_prime/tools/file_ops.py`

`FileWorkspace.edit_file(path, diff) -> dict` mirroring `patch_file` (root jail, missing-file and non-UTF-8 errors, write only after the pipeline returns), but calling `apply_edit`. Success returns `{"path", "applied": True, "method"}`. Total repair failure returns `{"error": "hunk context does not match", "path"}` — the same shape as `patch_file` — and the file is byte-for-byte unchanged.
