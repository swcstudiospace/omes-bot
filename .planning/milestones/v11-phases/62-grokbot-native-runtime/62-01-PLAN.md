# 62-01: Bearer security core + tool-call interceptors + runtime loader

## Objective

Provide the building blocks the remote host composes: constant-time bearer verification, a pure-ASGI
auth layer that never accepts query-string tokens, bind-safety checks, tool-call interceptors (scope,
audit, in-flight accounting), and a fail-closed `load_runtime` that both transports use.

## Change

1. Create `omega_prime/grokbot/security.py` exactly per the contract in `62-CONTEXT.md` (`<contracts>`):
   `Principal`, `TokenStore`, `hash_token`, `generate_token`, `parse_bearer`, `is_loopback_host`,
   `check_bind_safety`, `SecurityConfigError`, `AuthMiddleware`, `principal_from_scope`,
   `principal_from_request`, scope constants. Details:
   - `TokenStore.verify` hashes the presented value once, then loops over ALL entries calling
     `hmac.compare_digest`, remembering the match, so timing does not reveal which entry matched or how many.
   - `parse_bearer("Bearer abc")` -> "abc"; "bearer abc" ok; "Bearer  abc", "Bearer a b", "Basic abc",
     "", None -> None.
   - `is_loopback_host`: use `ipaddress` for literals (`127.0.0.0/8`, `::1`), plus "localhost"; strip
     `[` `]`; the wildcard binds `""`, `0.0.0.0`, `::` are NOT loopback; unparsable names other than
     localhost are NOT loopback.
   - `AuthMiddleware` is a plain class with `async def __call__(self, scope, receive, send)`; it builds
     the 401 response by sending `http.response.start` / `http.response.body` directly (or with
     `starlette.responses.JSONResponse(...)(scope, receive, send)`). Compare the request path exactly for
     public paths. The `on_failure` callback must never receive the token, and an exception inside it must
     not change the 401.
2. Create `omega_prime/grokbot/interceptors.py` per the contract: `ToolCall`, `ToolDenial`, `ToolOutcome`,
   `ToolCallInterceptor` (typing.Protocol), `call_from_context`, `run_tool_call`, `ScopeInterceptor`,
   `AuditInterceptor`, `InFlightInterceptor`. `AuditInterceptor` takes any object with a compatible
   `log_event` (declare a small Protocol; do not import the tracer class at runtime). Use
   `omega_prime.grokbot.audit.sanitize_payload` for the `redacted` args mode (that function exists today).
   `call_from_context` reads `ctx.request` defensively (`getattr`), takes the principal via
   `principal_from_request`, and `request_id` from `request.state.request_id` when present.
3. Edit `omega_prime/mcp_server.py` (library part only; do NOT touch `main()` or its argparse):
   add `RuntimeConfigError`, `Runtime`, `load_runtime` per the contract. Roster path and policy path are the
   ones `main()` uses today (`root/omega_prime/contracts/tool-rosters/omega-prime.yaml`,
   `.../policies/omega-prime.json`). Error messages are one line and keep today's wording
   ("cannot read roster <path>: <exc>", "cannot load seat policy: <exc>", "bad approval ..."). Compute
   `tool_names` from `registry.schemas()` filtered by the roster exactly as `_mcp_tools` does, and
   `gated_tools` with the registry's approval predicate. Extend `call_tool_handler(registry, roster=None,
   *, interceptors=(), transport="stdio")` and `build_server(..., interceptors=(), transport="stdio")`:
   build the `ToolCall` with `call_from_context`, execute through `run_tool_call`, keep the existing roster
   denial (`policy forbids <name>`) and the `is_error` rule (`"error"` key not None), and return a denial as
   an error result. Behavior with no interceptors must be byte-for-byte what it is today.

## Edge cases

- `ctx.request` is None (stdio) -> principal None; `ScopeInterceptor` allows (local operator).
- `ctx.request` present but unauthenticated principal (no-auth loopback) -> principal None -> allowed.
- Arguments that are not a dict (None) -> treated as `{}`.
- An interceptor `before` raising -> denial `interceptor_error`; `after` still runs for those whose
  `before` ran; an `after` raising never breaks the response.
- `load_runtime(env=None)` uses `os.environ`; never mutates it.
