# Plan 50-01: Responses mode + streaming

**Phase:** 50 (PCUR-03, PCUR-04)
**Mode:** Inline (no planner/executor agents in this runtime)

## Design

- **Routing**: `OpenAIProvider.api_mode` default `"auto"` (auto |
  chat_completions | responses). auto → responses iff base_url is
  api.openai.com, else chat_completions. Grok keeps explicit
  chat_completions. api_mode is declarative-only elsewhere — no fallout.
- **Responses wire**: POST `{base}/responses`, body `{model, input, tools?,
  store: false}`; transcript → input items (text rows, function_call,
  function_call_output); response `output` items → assistant row
  (output_text + refusal text joined; function_call → tool_calls;
  reasoning skipped). `status: failed` → ProviderError; `incomplete`
  parses what's there. `parse_response` sniffs `choices` vs `output`.
- **Fallback**: `Provider.fallback_request(...)` → None by default;
  OpenAI returns a chat_completions request when effective mode is
  responses and the error is 404 or 401/403 naming responses.
  `ProviderModel` tries it once, sets `last_fallback = True`.
- **Responses usage**: OpenAI `parse_usage` also maps input/output_tokens.
- **Streaming**: `Transport.stream(url, headers, body)` yields text lines.
  `HttpTransport` implements SSE line iteration (retries only before the
  first byte); `FakeTransport` replays scripted lines. Per-provider
  `stream_request` (chat-shape for OpenAI-family incl. stream_options
  usage; Anthropic stream:true; Gemini streamGenerateContent alt=sse;
  Ollama stream:true NDJSON) + `parse_stream(lines)` → (row, usage|None).
  `ProviderModel(stream=True)` uses it; loop unchanged. Responses
  streaming deferred (documented in code).
- **Usage in streams**: captured opportunistically from usage-carrying
  chunks (OpenAI final chunk, Anthropic deltas); absent → None.

## Tests (all hermetic)

- Routing pinned: openai.com → /responses; custom base → chat; explicit
  modes forced; Grok → chat.
- Responses round trip (text + function_call + usage + failed/incomplete).
- Fallback: 404 → chat retry, last_fallback True; 401 naming
  api.responses.write → fallback; 400 → no fallback.
- parse_response shape sniff incl. neither-shape error.
- Streaming per provider behind scripted lines incl. usage + junk lines;
  HttpTransport.stream over a scripted SSE peer (status/headers/framing);
  no-retry-after-first-byte; transport-without-stream errors;
  loop end-to-end with stream=True ProviderModel.
