# Plan 49-01: Retry 408/429, usage accounting, current defaults

**Phase:** 49 (PCUR-01, PCUR-02, PCUR-05)
**Mode:** Inline (no planner/executor agents in this runtime)

## Findings

- `HttpTransport` already retries connection/timeout/5xx; the gap is 408
  and 429 (rate limits are the common model-API transient). 404 stays final.
- Usage exists nowhere; the model span (`kind="model"`) is the natural sink.
- No documented model IDs exist; `claude-1` in one fixture is the only stale
  ID. Anthropic `max_tokens: 4096` truncates codegen.
- Base docstring claims "no retries" — stale; transport has them.

## Design

- **Retry**: 408 + 429 join the retryable set. `Retry-After` (seconds) is
  honored up to a 60s cap; the sleep is `max(backoff*(attempt+1),
  retry_after)` and still skipped entirely when `backoff=0` (tests never
  sleep). `_request` returns headers; `_Retryable` carries `retry_after`.
- **Usage**: `Provider.parse_usage(payload)` → normalized
  `{prompt_tokens, completion_tokens, total_tokens}` (found ints only, no
  synthesis; bools excluded). Per-provider key maps (OpenAI/Grok,
  Anthropic input/output, Gemini usageMetadata, Ollama eval counts).
  `ProviderModel.complete` stores `last_usage`; the loop adds it to the
  model span when present (getattr — ScriptedModel unaffected).
- **Defaults**: Anthropic `max_tokens` 4096 → 8192; fixture `claude-1` →
  `claude-sonnet-4`; `ANTHROPIC_VERSION` stays (verified current).
- Docstring in base.py corrected.

## Tests (all hermetic)

- Socketpair fixture gains per-attempt extra headers; new cases: 429→200,
  429 + Retry-After honored (sleep recorded via monkeypatch), cap at 60,
  408→200, 429 exhaustion, backoff=0 never sleeps.
- `parse_usage` per provider + unknown-shape → None.
- `ProviderModel.last_usage` set/absent; loop span carries usage with a
  scripted usage payload, omits without.
- Anthropic body asserts `max_tokens == 8192`.

## Verification

- Suite + evals + assemble + ruff + mypy green.
- No `time.sleep` wall time in tests (Retry-After sleeps asserted via
  monkeypatched recorder, never real).
