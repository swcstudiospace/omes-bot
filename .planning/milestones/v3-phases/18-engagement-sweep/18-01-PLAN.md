# Plan 18-01: Sweep routine with drafts and checkpoints

## Goal

A sweep fetches fresh mentions, composes one reply draft per mention through an injected composer, and queues the drafts without publishing. Each mention checkpoints as it is drafted, so an interrupted sweep resumes without duplicating drafts. Blank drafts are skipped and recorded, never retried.

## Starting Point

## Task 1: Sweep routine

### `omega_prime/routines/sweep.py` (new package `omega_prime/routines/`)

`sweep_mentions(client, composer, *, directory, sweep_id, user_id=None, max_results=10) -> dict`:

- `sweep_id` follows the session id rule (`^[a-zA-Z0-9][a-zA-Z0-9._-]*$`); violations are `ValueError`.
- State file `{directory}/sweeps/{sweep_id}.json`: `{"drafted": [mention ids], "drafts": [{"mention_id", "reply_to", "text"}], "skipped": [mention ids]}`. Missing file starts empty; corrupt JSON is a `ValueError` naming the file.
- Fetch mentions once. For each mention with an `id` not in `drafted` or `skipped`: call `composer(mention) -> str`. A blank/non-string draft records the id in `skipped`. Otherwise append `{"mention_id", "reply_to": id, "text"}` to `drafts` and the id to `drafted`. Checkpoint atomically after every mention, including skips. A composer raising propagates after checkpointing everything before it.
- Return `{"sweep_id", "drafts": [...drafted this run...], "skipped": [...skipped this run...], "total": len(all drafts)}`.
- Mentions without an `id` are ignored (not checkpointed, not returned).
