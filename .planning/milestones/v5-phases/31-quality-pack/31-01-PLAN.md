## Task 1: quality family

### `omega_prime/tools/quality.py` (new)

`QUALITY_TOOL_NAMES` (8): `qua_gates_run`, `qua_greptile_review`,
`qua_receipt_approve`, `qua_waiver_record`, `qua_contract_ack`,
`qua_contract_ack_status`, `qua_supply_chain_check`, `qua_secret_scan`.

`QualityContext`: `root`, `run` (default subprocess), `greptile`
(trigger/get/comments, default unconfigured), `acks` (AckStore),
`vcs` (diff seams, default git), `repo_slug` (default this repo).

- Gates run: pytest suite + evals runner + assemble check via the runner in
  the working tree (no ref export in Omega Prime); per-gate exit/output + `ok`.
- Greptile: trigger/get/comments passthrough with the desk notes.
- Receipt approve: read/validate/stamp/write under root; self-approval
  refused; no push (operator commits).
- Waiver: build + write the waiver record under root; no push.
- Contract ack/status: JSON ack store; proposal consumers read from
  `contracts/changes/<id>.json` (YAML unreadable without a parser — noted).
- Supply chain: desk lockfile/manifest lists + unpinned/git regexes verbatim.
- Secret scan: redact-diff scan of given files (default: whole tree ≤2000).

`register_quality_tools` with the drift guard. Approval on greptile,
approve, waiver, ack (desk write kinds).
