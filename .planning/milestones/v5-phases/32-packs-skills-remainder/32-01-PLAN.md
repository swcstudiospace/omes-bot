`http` (callable `(method, url, headers, params, json, timeout) ->

`("web", "android", "ios")`), `timeout` (default 10.0).

in memory:

- Tools load/unload: unknown app → not_found with available sorted;

  (`MAX_LIVE_TOOLS = 20` ported); records carry app + task_id.
- API smoke: GET `{base}/health` with `X-Desk-Environment`, ms timing;
  unconfigured base → not_configured.
- Supabase query: `read_only_sql` guard first (desk regexes verbatim:
  SELECT/WITH only, no write keywords, one statement), then POST
  `{base}/desk/query` with sql + limit.
- Push test: POST `{base}/desk/push-test` with platform/device_label/
  title/body/test_only=true; upstream error → failure.
- Feature flags / crash reports / scoreboard / store listing / render
  job: desk paths, params, and response shapes verbatim
  (`/desk/flags`, `/desk/crashes`, `/api/scoreboard`,
  `/desk/store-listing?store&locale`, `/api/render-jobs/{id}`).
