## Task 1: web family + browser review

### `omes/tools/web.py` (new)

`WEB_TOOL_NAMES` (6): `web_vercel_deployments`, `web_vercel_promote`,
`web_vercel_rollback`, `web_preview_check`, `web_bundle_secret_scan`,
`web_review_page`.

`WebContext`: `root`, `vercel` client (`deployments/deployment/promote/
rollback/allowed`, default unconfigured), `fetch` (`(url, timeout) ->
{status, headers, body}`, default stdlib urllib without redirects),
`browser` factory (default `PlaywrightBrowser`), `vision` transport
(default unconfigured), `artifacts_dir` for screenshots.

- Vercel: project allowlist gate, then passthrough; promote/rollback echo
  the approval (desk `approval_id` → Omes gate at registration).
- Preview check: fetch + status/latency/sha/content-type/redirect shape.
- Bundle scan: secret-shape scan of repo-relative files under root.
- Review page: preview_check connectivity + navigate + screenshot to
  artifacts dir + `vision_analyze(question)`; vision errors are reported,
  never fatal.

`register_web_tools` with the drift guard. Approval on promote/rollback only.

### `omes/tools/playwright_browser.py` (new)

{title, url, status}`, `snapshot() -> {title, url}`, `screenshot(path) ->
{path, bytes}`, `close()`. Constructor takes an injectable `launch()`
(default sync_playwright chromium); tests inject a stub launcher.
