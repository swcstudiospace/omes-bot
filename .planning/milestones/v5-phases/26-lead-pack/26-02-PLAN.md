# Plan 26-02: Lead routine, skill, evals

## Goal

The Lead flow runs end to end: claim intake, write tickets, dispatch,
consolidate receipts into a report (LEAD-01), with the pack skill and
deterministic eval coverage.

## Global Constraints

- Same as 26-01.

## Starting Point

26-01 families (`omes/tools/lead.py`), `TodoStore`, delegate machinery,
`validate_receipt`. Desk reference: LEAD prompt (intake→ticket→dispatch→
consolidate→report) and `verification-receipts` skill.

## Task 1: routine

### `omes/routines/desk_lead.py` (new)

`run_lead_pass(intake, dispatch, *, todos=None, limit=5) -> dict`:

- Claims up to `limit` open orders via the intake store (origin any).
- Writes one ticket per order (`{ticket_id, intake_id, ask, status}`) to the
  `TodoStore` when given (todos mirror ticket status).
- Dispatches each ticket through injected `dispatch(ticket) -> dict`
  (default: returns `{"error": "no dispatcher"}` and marks the ticket blocked
  — the desk never invents specialist work).
- Acks each intake done/blocked with the receipt summary; consolidates
  `{intake_id, tickets, receipts, report}` where `report` is plain text and
  every receipt passes `validate_receipt` (failures listed, never dropped).

### `omes/skills/lead-pack/SKILL.md` (new)

When to run the lead pass, ticket shape, dispatch/consolidate rules, receipt
requirements. Template may name it after this plan.

### `omes/tests/test_desk_lead.py` (new)

Fake dispatch returning valid receipts: pass shape, ticket/todo mirroring,
blocked path without dispatcher, invalid receipts listed not dropped, intake
statuses acked. Red-team additions to `omes/evals/cases/redteam.json`:
unapproved `lead_bus_start` refused; `lead_memory_retain` without evidence
refused (registry cases).
