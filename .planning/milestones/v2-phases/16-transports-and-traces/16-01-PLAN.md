## Starting Point

`Transport.post(url, headers, body)` is the seam `FakeTransport` already proves. The HTTP transport is a second implementation plus retries, timeouts, and host enforcement. Tracing threads a `Tracer` through the loop, the registry, and the workspace; nothing attached means nothing recorded.

## Task 1: Transport and traces

### `omega_prime/providers/http.py` (new)

`HttpTransport(policy=None, timeout=30.0, max_retries=2, backoff=0.1, connect=None)` (`connect(host, port, timeout, use_tls)` defaults to stdlib HTTP/HTTPS connections; tests inject a socketpair factory):

- `post(url, headers, body) -> dict`: when a policy is attached, parse the host and refuse with `ProviderError("network blocked to host <host>")` before any socket when the policy denies it. POST JSON with `Content-Type: application/json` merged under caller headers. Decode the JSON response (undecodable is a `ProviderError`).
- Retry transient failures: connection errors, timeouts, and HTTP 5xx, up to `max_retries` retries with `backoff * attempt` sleep between tries. HTTP 4xx raises `ProviderError` immediately with the status. Exhaustion raises the last failure as `ProviderError`.
- `timeout` must be positive; `max_retries` a non-negative int. Violations are `ValueError` at construction.

### `omega_prime/audit/trace.py` (new)

`Tracer(trace_id=None)` (default id is fresh hex):

- `span(kind, name, fields=None, duration_ms=None) -> dict`: append `{"seq", "ts", "kind", "name", "fields", "duration_ms"?}` (`ts` UTC ISO `Z`; `fields` defaults to `{}`). String field values are stored redacted. Return the span.
- `spans() -> list[dict]`: every span in order. `to_dict() -> {"trace_id", "spans"}`.

### Wiring (all optional, all default-off)

- `ToolRegistry(..., tracer=None)`: every dispatch appends one `kind="tool"` span with `fields={"verdict", "reason"?}` mirroring the audit verdict. A policy refusal additionally appends `kind="policy"` with `fields={"verdict": "denied", "reason": "policy forbids <name>"}`.
- `FileWorkspace(root, policy=None, tracer=None)`; `register_coding_tools(..., tracer=None)` threads it through. A read-only write refusal appends `kind="policy"` with `fields={"verdict": "denied", "reason": "policy forbids writing <relative>"}`.
- `Agent(tracer=None)`: the loop appends `kind="model"` around each `model.complete` with `fields={"model": type(model).__name__}` and measured `duration_ms` (rounded milliseconds, `>= 0`).

### Tests in `omega_prime/tests/test_transports.py`

A scripted HTTP peer over socketpairs (real request/response bytes; one pair per attempt) plus a refusing factory. No TCP, no external network.

1. The peer answers 503 to the first POST and an OpenAI-shaped payload after. A `GrokProvider` with `base_url` pointed at the fixture host completes through `HttpTransport` (no policy): two requests hit the peer and the parsed row matches.
2. A refusing factory raises `ProviderError` after retries (fast: `max_retries=1`, tiny backoff). A policy denying the fixture host raises before any socket (peer request count stays 0). A 4xx peer raises without retrying.
3. A registry with a tracer records an allowed tool span and, for a denied tool, a denied tool span plus a policy span. A workspace tracer records a policy span on a read-only write refusal. A scripted two-round loop turn with a tracer exports `to_dict()` with two model spans carrying `duration_ms >= 0`, seq increasing from 1.
