standards, and a KB sync pipeline publishing into `kb/` on schedule
(DOC-04, GRE-01, GRE-02, CIC-01).

- Repository root is `/root/src/repos/omega`. Do not push (push + PR once at milestone end).
- Do not modify `oh-my-pi/`, `hermes-agent/`, `~/src/repos/programming-desk`,

## Task 1: generated tool catalog

### `omega_prime/tooling/__init__.py`, `omega_prime/tooling/catalog.py` (new)

- `render(root, home) -> str`: build `default_registry`, walk roster order,
  emit `# Tool catalog` + `DO NOT EDIT` header + per-tool `## name`,
  family, description, required params, approval flag. Family from the
  canonical `*_TOOL_NAMES` tuples.
- `main(argv) -> int`: `--out PATH` (default `docs/tool-catalog.md`),
  `--check` (exit 1 when the committed file differs from fresh render).
- `docs/tool-catalog.md`: generated output, committed.

- `.greptile/config.json`: strictness 2, logic/syntax/style, triggerOnUpdates,

- `docs/greptile.md`: connect → review standards → KB publish pipeline →

- Run user-approved `greptile init` to connect the repo; record the outcome.

## Task 4: KB sync pipeline

### `omega_prime/greptile/__init__.py`, `omega_prime/greptile/kb_sync.py` (new)

- `McpHttpClient(base_url, token, opener=None)`: initialize handshake +
  `call_tool`; accepts plain-JSON and SSE (`data:`) responses; sends
  `Mcp-Session-Id` when the server issues one. stdlib only.
- `sync(repo, out_dir, client) -> dict`: list bases → match `repoName` →
  list documents (paginated) → fetch each → write mirror + `manifest.json`
  (versions, fetched_at, untrusted notice). Skips: missing token (exit 2),
  repo unenrolled (exit 3), nothing published (exit 0, no writes).
- Published files carry a synthesized/untrusted header. Secrets never printed.
- `kb/README.md`: what the mirror is + refresh pointer (committed; generated
  docs arrive via the workflow).

## Task 5: CI freshness

- `ci.yml`: new `docs` job (link-adjacent: runs the docs/public-repo focused
  tests + `catalog --check`). Existing three commands untouched.
- `.github/workflows/kb-refresh.yml`: weekly schedule + manual dispatch;
  skips without `GREPTILE_API_KEY`; runs sync; opens a PR on changes
  (commit → push branch → `gh pr create`).
