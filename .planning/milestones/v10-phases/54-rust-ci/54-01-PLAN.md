# Plan 54-01: Parity-oracle CI job + toolchain pin + deny gate

## Goal

CI keeps the Prime Agent Rust workspace green as the v10 parity oracle: a
path-filtered workflow clones the pinned upstream commit, builds and tests
the workspace on the pinned toolchain with `--locked`, runs the license
gate, and caches the build. A drift test keeps `VENDOR.md` and the
machine-readable pin in lockstep.

## Global Constraints

- Repository root is `/root/src/repos/omega-prime`. Commit only here. Do not push.
- Do not modify the `prime-agent/` checkout (ignored upstream).
- No new Python dependencies; stdlib only for the pin check.
- Existing CI jobs (`ci.yml`, `kb-refresh.yml`) unchanged.
- A completion claim cites the command and its exit code.

## Task 1: Pin file + drift test

Create `omega_prime/contracts/prime-agent.pin.json`:

```json
{
  "remote": "https://github.com/PrimeIntellect-ai/prime-agent.git",
  "commit": "967eb13fd488507af5f590e9c6ea8b2672f1fc05",
  "toolchain": "1.98.1",
  "known_failing_tests": [
    "acp_prompt_settles_after_rlm_quiescence",
    "acp_cancel_during_settle_cancels_the_subagents",
    "acp_eof_during_settle_exits_and_leaves_resident_subagents"
  ]
}
```

`known_failing_tests` carries the Phase 53 baseline evidence: the three
`pa-cli --test acp_mode_e2e` failures reproduce under full parallelism on
this host (ACP-stdio settle timing; pa-cli is out of v10 port scope). Each
entry is a documented exclusion, per the prime-agent AGENTS.md rule that a
disabled test carries its reason.

Create `omega_prime/tests/test_prime_pin.py`:
- loads the pin file (stdlib json), asserts required keys + SHA-shaped commit;
- asserts the commit string appears in `VENDOR.md` (drift guard);
- asserts every `known_failing_tests` entry names an `acp_` test (the
  exclusion set must stay scoped to the documented surface).

## Task 2: Parity-oracle workflow

Create `.github/workflows/rust-parity.yml`:

- Triggers: push/PR paths `omega_prime/contracts/prime-agent.pin.json`,
  `VENDOR.md`, `.github/workflows/rust-parity.yml`; weekly schedule
  (`cron`) so upstream-adjacent bit-rot surfaces; `workflow_dispatch`.
- Steps: checkout omega-prime → read pin (shell `python3 -c` json parse,
  no jq dependency) → `actions/checkout@v4` the pinned prime-agent commit
  into `prime-agent/` → `dtolnay/rust-toolchain@<pinned>` →
  `Swatinem/rust-cache@v2` (key includes the pin commit) →
  `cargo build --locked` → `cargo test --workspace --locked -- --skip
  <each known-failing test>` → `cargo deny check licenses` (uses the
  workspace's own `deny.toml`; install via `EmbarkStudios/cargo-deny-action`
  or `cargo install --locked`).
- Every step's exit code propagates exactly (the repo's fail-closed
  receipt convention; this workflow is shell-native, no ci_receipt.py
  needed — that helper is Python-gate specific).

## Task 3: Verify locally

- `python3 -c "import json; json.load(open('omega_prime/contracts/prime-agent.pin.json'))"` exit 0.

- Workflow YAML parses: `.venv/bin/python -c "import yaml; yaml.safe_load(open('.github/workflows/rust-parity.yml'))"` exit 0 (v8 workflows-parse convention).
- Full suite stays green: `.venv/bin/python -m pytest omega_prime/tests -q` exit 0.
